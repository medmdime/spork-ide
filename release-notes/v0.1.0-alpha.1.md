This is an alpha: an early build of both apps, not signed, with rough edges and missing pieces. Try it on projects
you have a copy of, and expect bugs.

## What's in it

**Spork IDE**, an IDE on Zed's engines with an interface of its own:

- The main window: tool windows on stripes around the editor, the main toolbar (project, branch and run widgets,
  Search Everywhere), editor tabs, the status bar, the main menu, light and dark themes, balloon notifications.
- Search and navigation: Search Everywhere, Find Action, Recent Files, the Switcher, File Structure, Go to Line,
  Find and Replace in Files, bookmarks.
- The editor: the gutter with folding and change markers, completion with documentation, intentions, parameter info,
  Markdown editing, column selection, clipboard history.
- Code intelligence over the language servers: Generate, Reformat, Optimize Imports, Rename and the other
  refactorings, Go to Declaration, Implementation and Usages, the call hierarchy, Inspect Code, Problems.
- Version control from Spork: the Git and Commit tool windows, the branches popup and Git menu, diffs, blame,
  shelves, stashes and worktrees; Local History.
- Projects: the Welcome window, recent projects, New Project, Get from Version Control, scratch files.
- Run and debug: run configurations, the Run and Debug tool windows, breakpoints; Docker in the Services tool window.
- The Settings dialog, and plugins: Zed's extensions (languages, themes, icon themes, snippets, language servers,
  debug adapters, context servers) install from the Plugins page.
- Java, a first slice: Maven and Gradle projects on Eclipse's JDT language server, the Build, Maven and Gradle tool
  windows.

**Spork**, the git client, on its own:

- Repositories in tabs; clone and create them.
- The commit graph with each commit's details, diffs (side by side too, images too), blame and file history.
- Staging of files or single lines, commits (signed too), fetch, pull and push with progress.
- Merge, rebase and interactive rebase, a three-way conflict resolver, cherry-pick, revert, stashes, tags, undo.
- Submodules, worktrees, git-flow, Git LFS, bisect; GitHub, GitLab and Gitea accounts and pull requests.
- Optional AI with your own provider: commit messages, reviews, pull request descriptions.

Not yet: signed apps, installers and updates; the editor's right-click menu is still the old one; Docker over SSH or
WSL.

## Opening the unsigned apps

**macOS.** Unzip and move the app to Applications. The first time, macOS refuses to open it: open System Settings ›
Privacy & Security and click Open Anyway beside the app's name, or run
`xattr -dr com.apple.quarantine "/Applications/Spork IDE.app"` (or `/Applications/Spork.app`) in a terminal.

**Windows.** Unzip, then start `Spork IDE\Spork IDE.exe` or `Spork\spork.exe`. When SmartScreen says "Windows
protected your PC", click More info › Run anyway. `Spork IDE\bin\spork-ide.exe` opens folders from a terminal.

**Linux.** Extract into `~/.local`, which puts the apps in `~/.local/bin` and their menu entries in
`~/.local/share/applications`:

```bash
tar -xzf Spork-IDE-v0.1.0-alpha.1-linux-x64.tar.gz --strip-components=1 -C ~/.local
tar -xzf Spork-v0.1.0-alpha.1-linux-x64.tar.gz --strip-components=1 -C ~/.local
```

The apps draw with Vulkan and need its driver, and the Wayland or X11, xkbcommon, fontconfig and ALSA libraries. On
Ubuntu or Debian:

```bash
sudo apt install git libvulkan1 mesa-vulkan-drivers libxkbcommon-x11-0 libwayland-client0 libx11-xcb1 libfontconfig1 libasound2t64
```
