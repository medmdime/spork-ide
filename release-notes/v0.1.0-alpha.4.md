This is an alpha: an early build of both apps, not signed, with rough edges and missing pieces. Try it on projects
you have a copy of, and expect bugs.

## What's new since alpha 3

**Code coverage.**

- Run with Coverage for Application, JUnit, TestNG, Kotlin and Spring Boot configurations, on Maven and Gradle
  projects: from the Run menu, the run widget, the gutter and the Project view.
- Covered, partly covered and uncovered lines in the editor's gutter; a click shows the line's hits and each branch's,
  and the tests that covered it.
- The Coverage tool window (classes, methods, lines and branches by package), percentages in the Project view,
  Manage Coverage Reports… (⌥⌘F6), Hide Coverage, and an HTML report.
- The configuration's Code Coverage options (the classes and packages to include or exclude) and Settings › Build,
  Execution, Deployment › Coverage. The coverage agent is downloaded the first time it's needed.

**Running tests.**

- Run and debug what the caret is in (⌃⇧R, ⌃⇧D): a test method, a test class or `main`, or the file or folder
  selected in the Project view; a file can be debugged without making a configuration first.
- A debugged test shows its test tree in the Debug tool window.
- Gradle projects debug their Java tests through Gradle, and a test in a multi-project build runs in its own project.
- JUnit 5 in Kotlin projects built with Maven.
- More test kinds: Tags, Category, UniqueId and All in directory, the fork mode, and TestNG's Suite and Group.
- The test runner's settings, Test History, Import Tests from File… and Rerun Automatically after a save.

**Spring Boot.**

- An Update button on a running application, and Update resources copying only the changed resources.
- The project wizard's Server URL, Retry, a warning on dependencies the chosen Spring Boot version can't take, each
  dependency's guide and reference links, Kotlin and Gradle Kotlin DSL projects, Reformat code.
- Endpoints in Search Everywhere and Navigate › Endpoint… (⇧⌘\), with HTTP Client, Documentation and Examples tabs.
- A first HTTP Client: `.http` files with completion and a run icon per request, Run All, environments from
  `http-client.env.json`, the responses in Services; Open in HTTP Client from an endpoint.
- The Beans tool window.

**Java and Kotlin debugging.**

- Exception breakpoints for a class, with caught or uncaught and class filters.
- In the variables: Inspect…, Mark Object…, Jump to Type Source, View as, Show types, Copy Value and Copy Name.
- Get Thread Dump, Export Threads… and Customize Threads View…; Evaluate's code fragment mode.
- Restart Debug when a change can't be reloaded; the Debug tool window's Layout Settings; stepping filters you add
  and remove.
- Kotlin method breakpoints and Kotlin exception breakpoints.

Not yet: signed apps, installers and updates; Convert Java to Kotlin and Kotlin's Generate items (the Kotlin language
server doesn't offer them yet); the HTTP Client's scripts and the Beans tool window's diagram.

## Opening the unsigned apps

**macOS.** Unzip and move the app to Applications. The first time, macOS refuses to open it: open System Settings ›
Privacy & Security and click Open Anyway beside the app's name, or run
`xattr -dr com.apple.quarantine "/Applications/Spork IDE.app"` (or `/Applications/Spork.app`) in a terminal.

**Windows.** Unzip, then start `Spork IDE\Spork IDE.exe` or `Spork\spork.exe`. When SmartScreen says "Windows
protected your PC", click More info › Run anyway. `Spork IDE\bin\spork-ide.exe` opens folders from a terminal.

**Linux.** Extract into `~/.local`, which puts the apps in `~/.local/bin` and their menu entries in
`~/.local/share/applications`:

```bash
tar -xzf Spork-IDE-v0.1.0-alpha.4-linux-x64.tar.gz --strip-components=1 -C ~/.local
tar -xzf Spork-v0.1.0-alpha.4-linux-x64.tar.gz --strip-components=1 -C ~/.local
```

The apps draw with Vulkan and need its driver, and the Wayland or X11, xkbcommon, fontconfig and ALSA libraries. On
Ubuntu 24.04 or newer:

```bash
sudo apt install git libvulkan1 mesa-vulkan-drivers libxkbcommon-x11-0 libwayland-client0 libx11-xcb1 libfontconfig1 libasound2t64
```
