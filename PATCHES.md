# Patches to Zed

Spork IDE's changes to Zed, so each `upstream/main` merge knows what to keep (ROADMAP, Principle 5). One line per
change, by crate. On a conflict:

- **keep deleted**: we removed it. Drop upstream's changes to it, and rework what they add that uses it.
- **keep ours**: take our side of the conflicting lines, and upstream's other changes around them.
- **ours**: only we have it; upstream doesn't touch it.
